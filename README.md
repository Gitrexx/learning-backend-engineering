# Backend Engineering — a personalized learning journey

A self-paced, interactive course that takes a strong programmer to a **production-ready backend
engineer** — the breadth (APIs, databases, distributed systems, reliability, security, ops) *and*
the trade-off reasoning that senior backend interviews look for. It's built for a machine-learning
engineer leveling up their backend fundamentals, so it draws the line to ML systems where natural.

**How it works:** it's a static site — no build step, no server. `ROADMAP.md` is the full plan.
Each sub-topic is a standalone, interactive HTML deep-dive in `/content`, indexed by
`content/manifest.json` and shown by the app in `index.html` (deployed to GitHub Pages). You learn
one deep-dive at a time; the app tracks what's built and what's still ahead.

**Growing the content:** deep-dives are created one at a time. Open this repo in Claude Code and
say *“continue the next deep-dive”* — the routine rules in `.claude/CLAUDE.md` tell it how to
research, write, and publish the next sub-topic as its own auto-merging PR.

👉 See **[`ROADMAP.md`](./ROADMAP.md)** for the full learning plan.
